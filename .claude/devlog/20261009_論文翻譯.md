# 論文翻譯

日期：2026-10-09

## 背景

待辦第 8 項的翻譯部分。英文論文翻成中文，原文與譯文可切換，上傳後手機也能切換。

使用者決定：模型先用 Sonnet；與摘要分開呼叫（合併只省一次全文輸入與固定開銷，輸出不變，
且無法分開選模型、易超輸出上限、重新生成摘要會連帶重翻）；清單在英文標題下方以小字顯示中文標題；
原文預設顯示中文，加中英切換。

## 做法

- `translate.py`：依段落順序分批（每批約 8000 字元，範例論文 105 段分成 10 批），同時送 3 批給 `claude -p`；
  參考文獻不翻；表格要求行數不變、只翻文字
- 每批完成就寫進 result 並存檔：本機有檔案寫本機，已上傳的同時寫回資料庫（`transcript`、`transcript_text`、
  `title_translated`），不需再次上傳。服務重啟或部分批次失敗時已翻好的不會遺失，再按一次只補沒翻到的段落
- 資料：逐段譯文存在 transcript 每段的 `translation`；標題譯文存在新欄位 `episodes.title_translated`
  （使用者執行 DDL）。`transcript_text` 在原文後接上譯文，手機用中文關鍵字也搜得到
- 本機 API：`POST /api/episodes/{guid}/translate`（背景執行，`force=true` 全部重翻）、
  `GET` 同路徑查進度；翻譯進行中擋下該篇的上傳與刪除（本機目錄會被清除，翻譯結束又把檔案寫回）
- 介面：
  - 本機：標題下方中文標題、側欄卡片中文小字；原文區塊「翻譯成中文」按鈕（顯示批次進度，
    翻譯中仍可看摘要）、中文／English 切換，章節標題跟著切換；下載 Markdown 依目前語言輸出
  - 手機：卡片與單集頁中文標題；原文分頁中英切換；搜尋關鍵字只出現在另一種語言時自動切過去定位
  - 手機後端：列表與單集詳細內容回傳 `title_translated`，搜尋也比對中文標題

## 實測與修正

- 範例論文（Sonnet）：105 段全數翻完，章節標題、內文、表格（39 行對 39 行，數字未動）都正確，沒有簡體字
- 原本譯文會再經 OpenCC s2tw，結果把兩岸通用字誤轉（佛羅里達→佛羅裡達、本台→本臺）。
  模型輸出本來就是繁體，移除這一步，簡繁要求交給 prompt；本篇三處已手動改回
- 第一次測試時改了後端程式，服務自動重載中斷翻譯，已完成的批次全部遺失；因此改成每批完成就存檔
