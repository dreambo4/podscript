# 快速捲動（列表日期、逐字稿章節）

日期：2026-10-07

## 需求

1. 手機列表頁加上 Google 相簿式的日期快速捲動：捲動時右緣浮出把手，拖曳時顯示年份刻度與目前年月
2. 逐字稿與原文的章節也套用同樣的快速捲動，刻度與泡泡顯示章節標題

## 第一版（`06aabe0`）

取代原本右側一排月份數字：

- 把手位置 = 目前捲動量在「第一個分組 ~ 頁尾」之間的比例，拖曳時反向換算成捲動量
- 捲動時浮出、閒置 1.5 秒淡出；拖曳時顯示年份刻度（間距小於 26px 略過）與目前年月泡泡
- 泡泡附近的年份刻度暫時隱藏，避免疊字
- 原本為月份數字保留的卡片右側留白移除

### 列表很短時拖到底停在錯的月份

使用者回報依發佈日期排序拖到底仍顯示「2026年9月」。9 集的列表只能捲 535px，
末段分組根本捲不到畫面頂端，而泡泡以「捲到頂端的分組」判斷。

改為「判斷線」：平常貼齊畫面頂端，進入最後一個畫面高度的捲動量後逐漸移到畫面底部，
拖到底時落在最後一組；年份刻度用同一套換算（`scrubberLineAt` 與其反函數 `scrubberScrollForLine`）。
同時卡片日期改顯示目前排序依據的欄位，與分組標題一致。

## Safari 拖曳跳動（`80263bf`～`97f9e63`）

Android Chrome 正常、只有 iOS Safari 拖曳時閃跳。前四版都在補症狀：

| commit | 做法 | 結果 |
|---|---|---|
| `80263bf` | 換算基準拖曳期間固定，把手直接跟手指，`touchmove` preventDefault | 好一點，仍閃 |
| `cafb231` | 改用 `screenY` 計算位移 | 仍閃 |
| `e20186b` | 最近三筆取中位數濾離群值；`html { overflow: hidden }` 鎖捲動 | 輕滑就跳到頂或底 |
| `f8bb38f` | 拿掉 `overflow: hidden` | 仍閃 |
| `97f9e63` | **拖曳期間不捲動頁面，以 transform 位移內容預覽，放開才 scrollTo 一次** | 解決 |

排查方式：請使用者錄螢幕，用 ffmpeg 抽 60fps 畫格，以 numpy 逐格量測把手位置（固定欄位的白色連續段）
與內容位移（相鄰畫格的垂直互相關），找出「單一畫格跳開再彈回」的模式。

結論：iOS Safari 高頻程式捲動整頁時，觸控座標、fixed／sticky 元素與頁面位置會對不上；
對 `<html>` 設 `overflow: hidden` 會重設捲動位置。教訓已寫入全域 CLAUDE.md。

transform 預覽期間分組標題改為 `position: static`，顯示在內容中的原位，放開後恢復固定。

## 章節快速捲動（`847048e`、`9a5fefd`、`744d334`）

- 快速捲動抽成 `createScrubber(config)`，列表（依年月）與逐字稿（依章節）各一個實例
- 逐字稿實例：區段為 `#transcript .chapter[id]`；固定高度為 topbar＋分頁列；
  位移預覽的內容為 hero、分頁列與逐字稿區塊（不含 fixed 的命中導覽列）
- 拖曳期間分頁列與章節標題也取消固定
- 至少 2 章才顯示；泡泡與刻度一律顯示章節標題（使用者先後要求文章、Podcast 都不要「第 N 章」與開始時間），長標題截斷

## 驗證

- headless Chrome 以 CDP 模擬分步拖曳，記錄每步的手指、把手、捲動量與泡泡；長列表、9 集短列表、
  注入離群座標等情境
- 拖曳中（transform）與放開後（實際捲動）截圖比對位置一致
- iOS Safari 的行為只能由使用者實機確認，每版部署後由使用者錄影回報
