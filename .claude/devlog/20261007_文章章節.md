# 文章章節

日期：2026-10-07

## 背景

章節導覽原定「文章不做章節」（見 `20261006_章節導覽本機.md` 已定案第 5 點）。
使用者看到報導者書摘（73 段）沒有章節，改決定：**所有文章都做章節**。

## 做法

文章的段落時間都是 0，無法用 `start` 定位，改用段落編號：
- `format_text`：文章每段開頭加 `[n]`（1 起算），供模型回傳章節從第幾段開始；標題行不編號
- `summary.py`：
  - 新增 `ARTICLE_CHAPTER_RULES`（約每 1000 字一章，至少 2 章、最多 12 章，`paragraph` 照抄 `[ ]` 內數字）
  - 業配規則抽成 `SPONSOR_RULES`，Podcast 與文章共用
  - `ARTICLE_PROMPT` 加 chapters；新增 `ARTICLE_CHAPTERS_PROMPT`；`generate_chapters` 加 `kind`
- `chapters.normalize_paragraphs`：轉為 0 起算索引存成 `{"paragraph", "title"}`，
  逐章過濾超出範圍、倒退、同段；第一章不在第 0 段時補「前言」；不足 2 章整組不用
- `pipeline._summary_transcript`：文章一律由 result 重建全文檔，避免沿用今天之前寫出、沒有段落編號的 `transcript.txt`
- `server.py`：補章節端點不再擋文章
- 前端（本機、手機）：`chapterStarts` 統一算出「各章從第幾段開始」，Podcast 比對 `start`、文章用 `paragraph`；
  文章的目錄與章節標題不顯示時間；本機 Markdown 下載的原文也加章節標題
- Bruno：本機「單集內容」「補上章節」、手機「單集詳細內容」說明更新
