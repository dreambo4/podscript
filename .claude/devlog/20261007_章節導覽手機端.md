# 章節導覽（手機端）

日期：2026-10-07

## 背景

todo #3 第二階段。本機端已完成並 commit（`35b6431`，見 `20261006_章節導覽本機.md`），
資料庫 `episodes.chapters` 已有 8 集章節。本階段讓手機詳細頁的逐字稿分頁顯示章節。不需 DDL。

## 做法

- 手機後端 `DETAIL_COLUMNS` 加 `e.chapters`，回應新增 `chapters`（空值回 `[]`）
- 手機前端（沿用本機端做法）：
  - 逐字稿分頁上方放可收合的章節目錄，點了捲到該章
  - 每章包成 `<section class="chapter">`，章節標題 sticky
  - 手機的「摘要／逐字稿」分頁列本身已 sticky 在頂部列下方，章節標題要再疊在它下面：
    新增 CSS 變數 `--subtabbar-h: 45px`（實測分頁列高度），
    `top` 與 `scroll-margin-top` 皆為 `--topbar-h + --subtabbar-h`
  - 沒有章節（含文章）時不顯示章節區
  - `renderTranscript` 由逐一 `createElement` 改為組字串，搜尋命中標亮（`highlightHtml`）照舊；
    YouTube 時間戳連結的 href 補上 `escapeHtml`
- Bruno：更新「單集詳細內容」說明

## 驗證

`mobile-web` 複製到暫存目錄、`config.js` 指向假的 API 位址，以 headless Chrome（390×844）
透過 DevTools 協定攔截 API，回傳本機服務取得的真實單集資料（ADHD 那集，96 段、15 章）：

| 情境 | 結果 |
|---|---|
| 分頁列實際高度 | 45，與 `--subtabbar-h` 一致 |
| 捲到第 4 章中段 | 第 4 章標題 top = 101（分頁列下緣） |
| 第 5 章標題在分頁列下 25px | 第 4 章被推到 58（藏到分頁列後），第 5 章在 126，不重疊 |
| 點目錄第 8 章 | 標題 top = 101 |
| 深色模式 | 標題背景不透明，文字不透出 |
| 搜尋「過動」 | 5 處標亮、切換列出現；第 2 處捲到畫面中央（449），未被章節標題遮住 |

測試時發現搜尋「妥瑞」為 0 處：逐字稿把該詞辨識成別的字（章節標題有、逐字稿沒有），非程式問題。
