# 思辨紀錄跨電腦同步

日期：2026-10-08

## 背景

使用者有兩台 Mac，思辨練習紀錄 `notes/<guid>.md` 原本只留本機。
repo 是公開的（GitHub `dreambo4/podscript`），紀錄不能進 git；
使用者選擇沿用論文原檔的做法，同步到 Supabase Storage（另一選項 iCloud Drive 需兩台登入同一 Apple ID，未採用）。

## 做法

- 使用者建立 `notes` bucket（不公開、單檔 1 MB、只收 `text/markdown`）
- `src/podscript/storage.py` 改為兩個 bucket 共用：
  - 抽出 `_upload`／`_download`／`_list`，論文的 `upload_paper` 等介面不變；`BUCKET` 改名為 `PAPERS_BUCKET`
  - 新增 `upload_note`／`download_note`／`list_notes`，`StoredNote` 帶 `updated_at` 與 `md5`
  - 物件名稱改以 `quote()` 編碼
- `scripts/notes.py`：`sync`／`pull`／`push`
  - 逐份比對內容 MD5（Storage 的 eTag 即檔案 MD5，已以 `md5 -q` 對照論文 PDF 確認），相同就略過
  - 不同時比較本機修改時間與 Storage 上傳時間，較新的一方覆蓋另一方
  - 只有一方有的檔案直接複製；不刪除任何一方的檔案
  - 下載後把本機修改時間設為上傳時間
  - 原本只比時間的版本有漏洞：上傳時間一定晚於本機修改時間，下次 sync 會誤判為遠端較新而重新下載，改以 MD5 先判斷
- `.claude/思辨練習.md`：練習開始前、寫完紀錄後各執行一次 `sync`
- `CLAUDE.md`、`.gitignore`、`.env.example` 說明更新

## 驗證

- `sync` 上傳現有 2 份；再執行一次為 0 下載 0 上傳
- 從 Storage 下載到暫存目錄，與 `notes/` `diff -r` 一致
- 以暫存目錄模擬另一台電腦（只呼叫 `plan()`，不實際傳輸）：
  - 少一份、另一份剛修改 → 下載缺的、上傳改過的
  - 內容不同但本機修改時間較舊 → 以 Storage 為準下載
- `scripts/paper.py list` 在重構後仍正常

## 異動摘要

- 修改 `src/podscript/storage.py`（兩個 bucket 共用）
- 新增 `scripts/notes.py`
- 更新 `.claude/思辨練習.md`、`CLAUDE.md`、`.gitignore`、`.env.example`

## 影響範圍

- 本機：論文指令介面不變；server 未引用 `storage.py`
- 手機：無
- 資料庫：無 DDL；Storage 新增 `notes` bucket（使用者建立）
